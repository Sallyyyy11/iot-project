# Lab session checklist (board available only in lab)

**Before the lab (home):**
- [ ] Agree on test goals and responsible members.
- [ ] Review wiring/pinout/power requirements against official hardware documentation.
- [ ] Prepare build dependencies, firmware files, credentials in local config and test scripts.
- [ ] Write exact test cases and expected results.

**At the lab:**
- [ ] Photograph wiring and record device/firmware version.
- [ ] Flash tested build and capture serial logs.
- [ ] Verify sensor telemetry, inter-device communication and CoreIOT dashboard.
- [ ] Test remote commands, failure/reconnect behavior and claimed technology elements.
- [ ] Save evidence named by feature ID and technology code (example: `F01_T06_2026-11-xx.log`).

**After the lab (home):**
- [ ] Upload safe evidence, fill in test-results and evidence-index CSVs.
- [ ] Write implementation notes, observed issues and solutions.
- [ ] Update report sections, issue tracker and GitHub pull requests.
